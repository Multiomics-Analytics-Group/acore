# Skills

Find the skills for acore in the [`skills`
folder](https://github.com/Multiomics-Analytics-Group/acore/blob/main/skills/acore/SKILL.md).

You can use the GitHub command line interface to add it to your machine, see [GitHub
CLI](https://cli.github.com/manual/gh_skill_install).

```bash
gh skill install Multiomics-Analytics-Group/acore/
```
